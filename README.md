# Tarmar Studio feedback

This is where players of [Tarmar Studio](https://tarmar.origamisoftware.com) leave comments.

Found a bug, hit something confusing, or have an idea for the game? [Open an issue](https://github.com/smarks/tarmar-feedback/issues/new) and say what happened or what you'd like. A screenshot or the page address helps.

You need a free GitHub account to open an issue.
